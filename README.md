# 🛒 سیستەمی مارکێت POS (Advanced Market POS System)
**وەشانی: v1.0.0 (Production Release)** | **سیستەمی فرۆشتن و کۆگای پێشکەوتوو بە زمانی کوردی بۆ ویندۆز**

سیستەمێکی بەهێز و سەردەمیانەی بەڕێوەبردنی مارکێت و کۆگا، بە تەواوی ئامادەکراو وەک بەرنامەی ڕاستەقینەی ویندۆز بە ئایکۆنی تایبەت، داتابەیسی خۆکار، پرینتەری پسووڵەی حەراری ESC/POS، ڕێکخستنی کێش و تەرازوو، و باکئەپی هەوری لە ڕێگەی تێلیگرامەوە.

---

## ⚡ شێوازی ١: بەکارهێنانی ڕاستەوخۆ بە فایلی دامەزراندن (Windows Installer Setup)
ئەگەر دەتەوێت ئەپەکە ڕاستەوخۆ لەسەر کۆمپیوتەری خۆت یان هەر کۆمپیوتەرێکی تر دابمەزرێنیت بەبێ پێویستی بە تێرمیناڵ و Node.js:

1. فایلی دامەزراندنی **`release/MarketPOS_Setup.exe`** بکەرەوە.
2. لە کاتی دامەزراندندا:
   - دەتوانی شوێنی دامەزراندن بگۆڕیت.
   - دەتوانی دیاری بکەیت کە ئایا **ئایکۆنی دێسکتۆپ (Desktop Shortcut)** دروست بکرێت یان نا بە خواستی خۆت.
3. دڵنیابە لەوەی خزمەتگوزاری **MySQL** (وەک XAMPP یان Laragon یان MySQL Server) کارایە لەسەر پۆرتی بنەڕەتی 3306.
4. لە یەکەم کردنەوەدا، ئەپەکە بە شێوەیەکی **خۆکار و نەبینراو** داتابەیسی `pos_db` و تەواوی خشتەکان و ٢٠ مەیگرەیشنەکە دروست دەکات بەبێ ئەوەی هیچ فەرمانێک لێبدەیت!

## 🛠️ شێوازی ٢: ڕێکخستن بۆ گەشەپێدەران (Developer Setup from Source)

### ١. پێداویستییەکان
- **Node.js** (v18 یان نوێتر)
- **MySQL / MariaDB** لەسەر پۆرتی 3306
- **Git**

### ٢. داگرتن و دامەزراندن
```bash
git clone https://github.com/arsh-kh/pos-system.git
cd pos-system

# دامەزراندنی پاکێجەکانی ڕووکار و باکئەند
npm install
cd backend && npm install && cd ..
```

### ٣. فایلی ژینگە (.env)
فایلی `backend/.env` دروست بکە:
```env
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=root
DB_NAME=pos_db
PORT=3001
TELEGRAM_BOT_TOKEN=8928798854:AAGlhCrK1qmBVTbNKlya71WBv_cERTbdX14
TELEGRAM_BOT_USERNAME=cashier_system_bot
```

### ٤. ئامادەکردنی داتابەیس بە یەک کلیک
تەنها دوو کلیک لەسەر فایلی **`setup_database.bat`** بکە، یاخود لە تێرمیناڵدا بنووسە:
```bash
node backend/init-db.js
```

### ٥. کارپێکردن
- **دێسکتۆپ (Electron):** دوو کلیک لەسەر **`start_pos.bat`** بکە.
- **براوسەر (Web Dev):** فەرمانی `npm run dev` لێبدە و بڕۆ بۆ `http://localhost:5173`.

### ٦. دروستکردنەوەی فایلی دامەزرێنەری ویندۆز (.exe)
```bash
npm run build
npx electron-builder --win nsis
```
فایلی نوێ لەناو فۆڵدەری `release/MarketPOS_Setup.exe` دروست دەبێت.

## 🌟 تایبەتمەندییە سەرەکییەکان (Features)
- 🛒 **کاشێر و فرۆشتنی خێرا:** خوێندنەوەی بارکۆد بە کەرتە چرکەیەک، پشکنینی ڕاستەوخۆی کۆگا.
- 📦 **بەڕێوەبردنی کۆگا و کاڵاکان:** جیاکردنەوە بەپێی بەش، کێش (کیلۆگرام/گرام)، و پۆلێنکردن.
- 💰 **قەرز و کڕیاران:** تۆماری پارەی ماوە، قیستەکان، ئاگاداری ڕادەبەدەربوونی قەرز.
- 🖨️ **پرینتەری حەراری (ESC/POS):** دەرکردنی پسووڵەی 80mm و 58mm بە دیزاینی سەردەمیانەی کوردی، لێدانی قاسە (Drawer Kick).
- 📲 **باکئەپی تێلیگرام:** ناردنی ڕاپۆرتی ڕۆژانەی داهات و فایلی باکئەپی داتابەیس بۆ چەن چات و گرووپی تێلیگرام بە شێوەی خۆکار لە کاتژمێر ١١:٥٩ی شەودا.
- 🔄 **هاوکاتکردنی فرە-دەزگا (Sync Engine):** کارکردن بە شێوازی ئۆفلاین و ئۆنلاین بە گۆڕینەوەی داتای گۆڕدراو.
- 🛡️ **ئاسایش و چاودێری (Audit Logs):** تۆمارکردنی هەموو دەستکاری و سڕینەوەیەک بە ناوی کارمەند و کاتی دیاریکراو.
